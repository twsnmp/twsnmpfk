# 総合レポート (Report)

各種センサーやエージェント端末から収集されたテレメトリ、イベント、トラフィック、環境測定データを集計・可視化・分析する画面。

## タブの構成

* **[センサー]** : 登録されている全センサー（twWifiScan、twBlueScan、twpcap、twwinlog、twagentneo、Syslog、Trap、MQTT等）の死活状態、種別、送受信メッセージ数、最終確認日時（Last Seen）の一覧、およびテレメトリ・リソース監視モーダルを表示するタブ。
* **[Wi-Fi AP]** : twWifiScan等によって検出されたWi-Fiアクセスポイント（SSID, BSSID, RSSI, チャンネル, ベンダー等）の一覧と、チャンネル別のAP分布グラフを表示するタブ。
* **[Bluetooth (BLE)]** : twBlueScan等によって検出されたBluetooth / BLEビーコンや端末（スマートウォッチ、タグ等）の検出レポートを表示するタブ。ベンダー割合の円グラフや受信信号強度（RSSI）の分布グラフ、検知端末一覧を表示します。
* **[環境センサー]** : SwitchBot等の環境センサー（温度、湿度、気圧、CO2等）、電力モニター、人感センサーの測定値を集計・可視化するレポートを表示するタブ。「環境センサー」「電力センサー」「人感センサー」のサブタブを切り替え可能です。
* **[Pcap パケット]** : twpcap等でキャプチャされたパケットデータを解析し、EtherType別フレーム数、DNSクエリ/応答統計（キャッシュ付き逆引き対応）、RADIUS認証フロー、TLS暗号化通信フローの集計・分析結果を表示するタブ。
* **[Windows ログ]** : twwinlog等から収集されたWindowsセキュリティイベントログ（Event ID、ログオン/ログオフ、アカウント操作、Kerberos認証、特権利用、プロセス起動、タスクスケジューラ）を集計・分析するタブ。KPIカードと詳細イベントモーダルを備えています。
* **[twagentneo]** : twagentneoエージェント端末から収集された稼働状態、AI脅威判定（tensai連携）、ファイル整合性監視（FIM）、セキュリティ構成評価（SCA）、およびプロセスTCP通信フローを集計・表示するタブ。

## ボタンの説明

* **[Clear All]** : 現在選択しているタブのレポートデータをデータベースから全消去するボタン。
* **[CSV]** : 表示中のレポートデータをCSV形式でエクスポートするボタン。
* **[Excel]** : 表示中のレポートデータをExcel形式（.xlsx）でエクスポートするボタン。
* **[Reload]** : レポートデータを最新の状態に再読み込みするボタン。
