# ポーリング編集

ノードに対して設定する各種監視項目（ポーリング）の新規作成および編集画面。

## 設定項目

* **ノード**
  ポーリングを紐付ける対象ノード（新規追加時は選択必須。編集時も変更可能）。
* **名前**
  ポーリングの名前。
* **レベル**
  障害発生時のステータスレベル（「重度」、「軽度」、「注意」など）。
* **種別**
  監視の方式（PING、SNMP、TCP、HTTP、gRPC、TLS、DNS、SSH/SFTP、Commandなど）。
* **モード**
  選択した種別に応じた動作モード。
  * **PING Smokepingモード (`smoke`)**: 短周期連続PING送信により統計量（最小/最大/平均/中央値応答時間、パケットロス率、ジッター等）を測定。
* **ログモード**
  結果ログの保存・処理方式（「保存しない」、「常に保存」、「状態変化時のみ保存」、「AI分析」）。
* **MQTTサーバーURL**
  ポーリング結果をMQTT送信する場合のブローカーURL（例: `tcp://localhost:1883`）。
* **トピック**
  MQTT送信先のトピック名（デフォルト: `twsnmpfk/polling`）。
* **送信するデータ名**
  MQTT送信する変数名（カンマ区切りで複数指定可能）。
* **AIモード**
  （ログモードが「AI分析」の時のみ表示）AI分析アルゴリズム（「Isolation Forest」、「ホテリング理論（Hotelling's Theory）」、「k近傍法（k-NN）」など）。
* **ベクトル化する変数名**
  （ログモードが「AI分析」の時のみ表示）AI分析対象とする数値データの変数名（カンマ区切りで指定）。
* **パラメータ**
  種別やモードに応じた設定値。
  * **PING Smokepingモードの例**: `count=10,size=64,ttl=64` （`count`: 連続送信回数、`size`: 送信サイズ、`ttl`: TTL）
  * **メール監視（IMAP/POP3）の例**
    * **メールサーバー**: IMAP/POP3サーバーのホスト名またはIPアドレス
    * **ポート**: ポート番号（IMAP: 993、POP3: 995など）
    * **ユーザー名**: メールボックスのログインユーザー名
    * **パスワード**: パスワード
    * **プロトコル**: IMAPまたはPOP3
    * **セキュア接続**: SSL/TLS有効化設定
    * **キーワード**: 件名や本文を検索するキーワード（オプション）
* **フィルター**
  ログ収集や特定データ抽出時の正規表現等による絞り込みフィルター条件。
* **抽出パターン**
  ログデータなどから変数として値を取り出すためのGrokパターン。
* **スクリプト**
  障害判定や独自変数の演算を行うJavaScriptコード（判定結果が `true` で正常稼働、`false` で障害）。
  * **PING Smokepingモードで利用可能な変数**:
    * `rtt` / `avg` / `mean`: 平均応答時間（ナノ秒単位）
    * `min`: 最小応答時間（ナノ秒単位）
    * `max`: 最大応答時間（ナノ秒単位）
    * `median`: 中央値応答時間（ナノ秒単位）
    * `jitter`: ジッター（`max - min`、ナノ秒単位）
    * `loss`: パケットロス率（%、`0.0` 〜 `100.0`）
    * `fail` / `lossCount`: ロスしたパケット数
    * `count`: 試行（送信）パケット総数
    * `ttl`: RecvTTL
    * 例: `loss < 10.0 && avg < 100 * 1000 * 1000` （パケットロス10%未満かつ平均応答時間100ms未満で正常）
* **ポーリング間隔**
  ポーリングを実行する間隔（秒）。
* **タイムアウト**
  応答待ちの制限時間（秒）。
* **リトライ**
  タイムアウト発生時の再試行回数。
* **障害時のアクション**
  障害検出時に実行するコマンドや通知（WOL、Mail、Webhookなど）。
* **復帰時のアクション**
  障害復帰時に実行するコマンドや通知。

## ボタンの説明

* **[保存]** ： 設定内容を保存。
* **[AIアシスト]** ： 自然言語等のプロンプトに入力したご要望をもとに、AI（LLM）が監視種別・パラメータ・JavaScriptスクリプト等を自動生成・提案するアシスト機能（AI連携が有効な場合のみ表示）。
* **[ヘルプ]** ： 本ヘルプを表示。
* **[キャンセル]** ： 変更を保存せずに画面を閉じる。
