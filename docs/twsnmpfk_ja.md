# はじめてのTWSNMP FK
日本で定番のSNMPマネージャー
復刻版

![h:256px bg right:30%](./images/appicon.png)

---

## はじめに

TWSNMPは日本で25年以上定番のSNMPv3に対応したSNMPマネージャです。
これを2023年の最新機技術で復刻したのがTWSNMP FKです。
コンテナで動作するTWSNMP FCはWebブラウザーからアクセスして操作しますが、FKは、デスクトップアプリであるためブラウザー不要です。

## Linux版

GitHubのリリースからパッケージ（`.tar.gz`形式）をダウンロードできます。

### Linux環境での起動と注意点
一般ユーザーとして実行すると、ICMP監視（RAWソケット）や特権ポート（514, 162等）の使用権限がないためエラーになります。
**`sudo` で直接アプリを実行しないでください**（GUIの表示サーバーと接続できなくなります）。

1. **特権の付与**:
   `sudo setcap 'cap_net_bind_service,cap_net_raw+ep' ./twsnmpfk`
2. **ARP監視ツールのインストール** (`arp`コマンドの追加):
   `sudo apt-get update && sudo apt-get install -y net-tools`
3. **一般ユーザーとしての起動**:
   `./twsnmpfk`

## はじめてのマップ作成の流れ

マップを作成する大まかな流れは、

- マップ上の適当な位置を右クリック
- メニューから「自動発見」を実行
- 検索するIPアドレス範囲を設定
- 自動発見を実行
- ノードの配置を調整
- ラインの接続

です。これで管理対象のネットワークに接続されたPCやルーター、サーバーなどを検索してマップに登録できます。

## 新機能の紹介

TWSNMP FKは、継続的に機能強化を行っています。v1.30.0以降に加わった主な新機能と改善点を紹介します。

### v2.2.0 の新機能

- **アドレス管理のAI解説**: アドレス管理（Address）画面にて、正常なアドレスの件数要約と、正常以外（IP重複、169.254 APIPA, IP変更, MAC変更など）の各アドレスエントリの具体データ（IP, MAC, 旧/新MAC差分, ノード名, ベンダー等）をAI（LLM）に送信し、全体の運用概要、各異常エントリの問題点、リスク、想定原因、推奨対策について個別かつ具体的な診断結果を出力。
- **ログビューからのAIポーリング自動作成**: Syslog, SNMP Trap, MQTT, NetFlow, sFlow の各ログ画面でエントリ選択時に `[AIアシスト]` ボタンを表示。ログ内容に基づいて適切なポーリング設定（種別・パラメータ・フィルター・Grokパターン・スクリプト）をAIが自動生成。
- **AI関連ボタンの条件付き表示**: AI設定（LLMプロバイダー設定）が有効な場合のみ、各画面のAI関連ボタン（AI診断、AI原因調査、AI解説、AIアシスト、AI説明等）を表示するよう改善。
- **ポーリング設定のノード指定改善**: ポーリング作成時のノード指定を必須化し、編集ダイアログでも対象ノードを変更可能に対応。

### v2.1.0 の新機能

- **マップエクスポート拡張**: PNG, SVG, PDF, Draw.io(XML/SVG), JSON, CSV, Excel(XLSX)でのマップ出力に対応。
- **AI（LLM）連携の強化**: 
  - **ノードのAI診断**: マップ右クリックメニューやノードリストから、ノードの状態・ログ・応答結果をAIが多角的に自動診断（コピー・保存対応）。
  - **イベントログのAI原因調査**: 発生イベントの原因と推奨対策をAIが自動分析。
  - **ポーリングAIアシスト**: プロンプトから監視設定・パラメータ・スクリプトをAIが提案・自動生成。
- **AI異常検知アルゴリズムの拡張**: 従来の Isolation Forest に加え、「ホテリングのT2 (Hotelling's T2)」および「k近傍法 (k-NN)」を選択可能。
- **MQTT機能の強化**: 最新受信データ（Payload）の構造化表示（JSON/TEXT/HEX等）およびMQTTトピックレポート表示。
- **テーブル操作の改善**: すべての複数選択テーブルでShiftキー範囲選択 (multi+shift) に対応。

---

### SNMPv3 セキュリティの強化 (v1.33.0)

SHA256/AES128 および SHA512/AES256 の認証・暗号化モードのサポートが追加され、最新のセキュリティ要件に合わせたネットワーク監視が可能になりました。

### マップと UI の改善 (v1.33.0)

- **ノードの IP アドレス表示**: マップ上のノードに IP アドレスを直接表示可能。
- **グループ描画アイテム**: マップ上のエリアやノードを整理するための「グループ（枠/背景）」アイテムを導入。
- **VPanel の強化**: ノードおよびネットワークレポートの仮想パネルにおいて、ズーム制御とポートの折り返し制御を可能に。
- **マップの視認性向上**: 未選択ノードの背景矩形を削除し、スッキリとした外観に。

---

### 描画アイテムの機能拡張 (v1.33.0)

描画アイテムの透明度（Opacity）設定への対応と、背景画像設定のUI改善。

### AI（LLM）統合機能 (v1.32.0)

AIを活用した強力な機能が大幅に追加されました。
- **MIBブラウザ**: 自然言語によるMIB検索と、AIによるオブジェクト解説。
- **ログ解析支援**: NetFlow、Syslog、SNMP Trapログに対するAIの解説。
- **レポートの要約**: AIによる定期レポートの自動要約。
- **マルチプロバイダー対応**: Gemini, OpenAI, Claude, Ollama をサポート。

---

TWSNMP FKは、ネットワークスイッチのFDB (Forwarding Database) テーブル情報から、各ポートに接続されている端末のMACアドレス、IPアドレス、ホスト名などの情報を可視化し、ネットワーク全体の接続状況を把握するための「ネットワークレポート」機能を提供します。

### レポートの表示

「ネットワーク」画面で、表示されている地図上のネットワークアイコンをクリックすると、そのネットワークの詳細なレポートが表示されます。このレポートには、FDBテーブル、各ポートの最終変化時刻などが含まれます。

### FDBテーブルの可視化

FDBテーブルの情報を元に、各ポートにどのMACアドレスが接続されているか、さらにそのMACアドレスに対応するIPアドレスやホスト名が一覧で表示されます。これにより、ネットワーク内のどのデバイスがどのポートに接続されているかを一目で確認できます。

### 回線検索

MACアドレスやIPアドレスを入力することで、目的の端末が接続されているスイッチポートを迅速に検索できます。
